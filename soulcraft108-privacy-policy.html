Soulcraft108 privacy policy

Effective October 19, 2026 · Applies to Soulcraft108 and its private app "Soulcraft108 Pin Planner"

Soulcraft108 Pin Planner is a private tool used only by the owner of Soulcraft108, a shop selling printable planners and spreadsheet templates. It creates Pinterest Pins for the shop's own published products and posts them to the shop's own Pinterest account. It has no other users and is not offered to the public.

What the app accesses

  • The Soulcraft108 Pinterest account's own boards and Pins, to create boards, publish Pins and read their performance (impressions, saves and clicks).
  • Basic account information for the same Pinterest account, to confirm which account is connected.
  • The Soulcraft108 Etsy shop's own published listings (titles, descriptions, images and listing links), read through the Etsy API, to build each Pin. No Etsy buyer, order or payment data is accessed.

It does not access other Pinterest users' content, messages, followers or personal information.

How data is stored

The Pinterest access tokens and the list of Pins created are stored only on the shop owner's own computer. Nothing is stored on any server operated by Soulcraft108, and no data is sold, rented or shared with anyone.

This website

This website has no sign-up, no cookies, no analytics and no tracking. It is hosted on GitHub Pages, which may keep standard server logs (such as IP addresses) under GitHub's own privacy policy.

How long data is kept

Data is kept only while the owner uses the tool. Disconnecting the app in Pinterest settings (Settings > Security > Apps) revokes access immediately, and the owner deletes the stored tokens.

Changes

If this policy changes, the new version is posted on this page with a new effective date.
